# SALORA 4-minute demo

1. Open the public landing page and explain the problem: a calendar shows bookings but not the consequence of a walk-in.
2. Sign in with the seeded demo owner account.
3. Show the live schedule and service economics.
4. Choose Haircut and run **Run decision simulation**.
5. Explain the returned state, revenue, wait, maximum delay and affected appointments.
6. Show alternative placements when available.
7. Accept the recommendation and refresh the schedule.
8. Close with: **SALORA helps independent salons say yes to more walk-ins without losing control of the schedule.**

Demo credentials are documented in the README and should be changed for any real deployment.
